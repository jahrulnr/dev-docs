# Edge Computing

## AWS Outposts

AWS Outposts adalah layanan terkelola sepenuhnya yang memperluas infrastruktur AWS, layanan AWS, APIs, dan tools ke virtually semua datacenter, ruang co-location, atau fasilitas on-premises.

## Kasus Penggunaan Umum
- Deployment cloud hybrid
- Aplikasi low-latency
- Persyaratan residensi data
- Migrasi aplikasi legacy

## Praktik Terbaik
- Rencanakan persyaratan kapasitas dengan hati-hati
- Konfigurasikan networking yang tepat
- Implementasikan monitoring dan manajemen
- Rencanakan maintenance windows

## AWS Wavelength

AWS Wavelength menyematkan layanan komputasi dan penyimpanan AWS dalam jaringan 5G, menyediakan infrastruktur mobile edge computing untuk mengembangkan, men-deploy, dan menskalakan aplikasi ultra-low-latency.

## Kasus Penggunaan Umum
- Aplikasi gaming real-time
- Kendaraan otonom
- Aplikasi IoT industri
- Pengalaman augmented reality

## Praktik Terbaik
- Desain untuk persyaratan ultra-low latency
- Gunakan tipe instance yang sesuai
- Implementasikan langkah keamanan yang tepat
- Monitor performa aplikasi
