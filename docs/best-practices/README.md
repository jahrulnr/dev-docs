# Best Practices
## Overview

Folder ini menyatukan prinsip, pola, praktik, dan anti-patterns yang menjadi pedoman untuk perancangan dan pembangunan sistem.

Struktur:
- architecture/: architectural styles & patterns
- principles/: prinsip desain dan kualitas kode
- patterns/: design, domain, data-access, transaction, integration, scalability, reliability, security, observability
- practices/: operational practices (CI/CD, IaC, dsb)
- anti-patterns/: daftar antipatterns dan mitigasinya

Catatan: Setiap topik memiliki versi bahasa Inggris (_en.md) dan Indonesia (_id.md) jika tersedia.
