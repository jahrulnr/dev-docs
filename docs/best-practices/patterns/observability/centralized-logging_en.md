# Centralized Logging
## Overview

Centralized Logging aggregates logs from services into a central system (e.g., ELK, Loki) for search, analysis, and alerting. Ini memungkinkan troubleshooting yang efisien dan pemantauan sistem terdistribusi.

## When to use
Use to simplify troubleshooting, correlate events across services, and support incident response.

## Example
Ship structured logs to Elasticsearch and visualize in Kibana.

## Pros / Cons
- Pros: Easier debugging, centralized search, retention and alerting.
- Cons: Storage costs, need for log management and retention policies.
