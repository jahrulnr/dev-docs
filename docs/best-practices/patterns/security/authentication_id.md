# Pola Authentication
## Gambaran Umum

Authentication memverifikasi identitas pengguna atau layanan (siapa Anda) dan merupakan langkah pertama dalam keamanan. Ini memastikan bahwa hanya entitas yang sah yang dapat mengakses sistem.

## Kapan digunakan
Selalu gunakan untuk sistem yang membutuhkan kontrol akses; terapkan authentication yang kuat untuk operasi sensitif.

## Contoh
Autentikasi berbasis JWT, OAuth2 authorization code flow, atau sertifikat klien mutual TLS.

## Kelebihan / Kekurangan
- Kelebihan: Esensial untuk keamanan dan akuntabilitas.
- Kekurangan: Jika salah konfigurasi, bisa dilewati; kredensial dan token harus dilindungi.

## Referensi
- Panduan OWASP authentication, spesifikasi OAuth2.
