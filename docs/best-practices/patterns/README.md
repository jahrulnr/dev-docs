# Patterns
## Overview

Kumpulan pola dari tingkat kode (design/), domain, akses data, transaksi, integrasi, skala, keandalan, keamanan, dan observability.

Subfolder:
- design/: GoF design patterns (Factory, Adapter, Strategy, dsb)
- domain/: DDD, Specification, Policy, Use Case Interactor
- data-access/: Repository, Unit of Work, CQRS, dsb
- transaction/: Saga, 2PC, Compensation
- integration/: Pub/Sub, Message Broker, ACL, dsb
- scalability/: Caching, Sharding, Throttling, dsb
- reliability/: Circuit Breaker, Retry, Timeout, dsb
- security/: Auth, OAuth2, mTLS, dsb
- observability/: Logging, Tracing, Health Check, Metrics

Setiap topik disediakan versi bahasa Inggris (_en.md) dan Indonesia (_id.md) bila relevan.
