# Practices
## Overview

Cara kerja dan operasional yang direkomendasikan untuk development dan deployment yang efisien.

## Subcategories

- **[Deployment](deployment/)**: Strategi deployment seperti Blue-Green dan Canary untuk minimize downtime.
- **[Integration](integration/)**: Praktik integrasi kode seperti CI/CD, Trunk-Based Development, dan Test-Driven Development.
- **[Feature Management](feature-management/)**: Teknik manajemen fitur seperti Feature Toggle.
- **[Infrastructure](infrastructure/)**: Praktik infrastruktur seperti Infrastructure as Code (IaC).
