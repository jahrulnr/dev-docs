# Deployment Strategies

Strategi deployment untuk meminimalkan downtime dan risiko saat rilis aplikasi.

## Strategies

- **[Blue-Green Deployment](blue-green-deployment_en.md)**: Switch traffic antara dua environment identik.
- **[Canary Deployment](canary-deployment_en.md)**: Gulirkan perubahan ke subset pengguna secara bertahap.
- **[Rolling Deployment](rolling-deployment_en.md)**: Update instances secara incremental tanpa downtime.
- **[Recreate Deployment](recreate-deployment_en.md)**: Shutdown versi lama sebelum deploy versi baru.
- **[A/B Testing Deployment](ab-testing-deployment_en.md)**: Test multiple versions dengan subset users untuk data-driven decisions.
- **[Shadow Deployment](shadow-deployment_en.md)**: Jalankan versi baru paralel untuk testing tanpa affect traffic.
