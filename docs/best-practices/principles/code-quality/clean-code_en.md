# Clean Code
## Overview

Clean Code emphasizes readability, simplicity, and maintainability by using clear naming, small functions, and predictable structure. Following these principles leads to code that is easier to understand, modify, and extend over time.

## When to use
Always—writing clean code improves long-term maintainability and reduces technical debt.

## Example
Prefer `calculateOrderTotal()` over ambiguous names; keep functions short and single-purpose.

## Pros / Cons
- Pros: Easier to maintain, review, and extend; lower bug rates.
- Cons: Requires discipline and code review culture.
