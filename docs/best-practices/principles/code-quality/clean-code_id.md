# Clean Code
## Gambaran Umum

Clean Code menekankan keterbacaan, kesederhanaan, dan maintainability dengan penamaan jelas, fungsi kecil, dan struktur yang konsisten. Mengikuti prinsip-prinsip ini menghasilkan kode yang lebih mudah dipahami, dimodifikasi, dan diperluas seiring waktu.

## Kapan digunakan
Selalu—menulis kode bersih meningkatkan maintainability jangka panjang dan mengurangi technical debt.

## Contoh
Gunakan nama `calculateOrderTotal()` daripada nama ambigu; pertahankan fungsi singkat dan bertanggung jawab tunggal.

## Kelebihan / Kekurangan
- Kelebihan: Lebih mudah dipelihara, direview, dan diperluas; menurunkan bug.
- Kekurangan: Memerlukan disiplin tim dan budaya code review.

## Referensi
- Robert C. Martin, "Clean Code"; praktik review kode.
