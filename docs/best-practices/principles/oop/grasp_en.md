# GRASP Principles
## Overview

GRASP (General Responsibility Assignment Software Patterns) provides guidelines for assigning responsibilities to classes and objects (e.g., Information Expert, Creator, Controller). These principles help in creating well-structured, maintainable object-oriented designs.

## When to use
Use when designing object-oriented systems to improve cohesion and responsibility distribution.

## Example
Information Expert: Give responsibility to the class with the necessary information.

## Pros / Cons
- Pros: Guides clear responsibility assignment and better design.
- Cons: Requires judgement, not a strict rule set.
