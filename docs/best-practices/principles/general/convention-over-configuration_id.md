# Convention over Configuration
## Gambaran Umum

Convention over Configuration mengurangi boilerplate dengan mengasumsikan default yang masuk akal, meminimalkan konfigurasi eksplisit. Prinsip ini membantu developer fokus pada logika bisnis daripada tugas setup yang repetitif.

## Kapan digunakan
Gunakan untuk mempercepat pengalaman developer dan mengurangi verbositas ketika konvensi cocok untuk proyek.

## Contoh
Framework yang auto-discover komponen berdasarkan struktur direktori atau pola penamaan.

## Kelebihan / Kekurangan
- Kelebihan: Setup lebih cepat, lebih sedikit kesalahan konfigurasi.
- Kekurangan: Konvensi mungkin membatasi atau mengejutkan jika tidak terdokumentasi.
