# Convention over Configuration
## Overview

Convention over Configuration reduces boilerplate by assuming sensible defaults and conventions, minimizing explicit configuration. This principle helps developers focus on business logic rather than repetitive setup tasks.

## When to use
Use to streamline developer experience and reduce verbosity when conventions suit the project.

## Example
Frameworks that auto-discover components by directory structure or naming conventions.

## Pros / Cons
- Pros: Faster setup, fewer configuration errors.
- Cons: Conventions may be restrictive or surprising if not documented.
