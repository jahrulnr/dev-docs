# Least Privilege
## Overview

Least Privilege grants the minimal permissions necessary for a user or service to perform its tasks, limiting blast radius. This principle reduces the impact of security breaches by restricting access to only what's required.

## When to use
Enforce for all accounts, services, and resources to minimize risk from compromised identities.

## Example
Grant read-only DB access to analytics jobs; grant write access only to specific services.

## Pros / Cons
- Pros: Limits damage from compromised credentials.
- Cons: Requires careful role design and ongoing maintenance.
