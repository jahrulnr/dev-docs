# Secure by Default
## Overview

Secure by Default means systems are configured with secure defaults (least privilege, safe network settings) and require explicit action to relax security. This approach ensures security is built-in from the start rather than added as an afterthought.

## When to use
Apply in product and infrastructure design to reduce accidental insecure configurations.

## Example
Default deny inbound network rules, strong password policies, and disabled debug endpoints in production.

## Pros / Cons
- Pros: Reduces attack surface and human misconfiguration.
- Cons: May require more explicit configuration for nonstandard use cases.
