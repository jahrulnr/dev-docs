# Zero Trust
## Gambaran Umum

Zero Trust adalah model keamanan yang tidak mengasumsikan kepercayaan implisit; setiap permintaan akses harus diautentikasi dan diotorisasi. Pendekatan ini memberikan keamanan yang lebih baik di sistem terdistribusi kompleks dengan verifikasi akses berkelanjutan.

## Kapan digunakan
Terapkan pada arsitektur terdistribusi modern dan lingkungan hybrid yang membutuhkan kontrol akses ketat.

## Contoh
Wajibkan autentikasi dan otorisasi untuk semua komunikasi service-to-service serta terapkan least privilege.

## Kelebihan / Kekurangan
- Kelebihan: Postur keamanan kuat, meminimalkan blast radius kebocoran.
- Kekurangan: Overhead operasional dan kompleksitas dalam penegakan kebijakan.
