# Zero Trust
## Overview

Zero Trust is a security model that assumes no implicit trust; every access request must be authenticated and authorized. This approach provides better security in complex, distributed systems by continuously verifying access.

## When to use
Use for modern distributed architectures and hybrid environments requiring strict access controls.

## Example
Require authentication and authorization for all service-to-service communication and enforce least privilege.

## Pros / Cons
- Pros: Strong security posture, minimizes blast radius of breaches.
- Cons: Operational overhead and complexity in policy enforcement.
