# Assume Breach
## Overview

Assume Breach is a security mindset that presumes a breach has occurred or will occur; designs focus on detection, containment, and rapid recovery. This proactive approach helps organizations prepare for inevitable security incidents.

## When to use
Adopt across security strategy to prioritize monitoring, incident response, and minimization of blast radius.

## Example
Implement comprehensive logging, anomaly detection, and automated isolation of compromised components.

## Pros / Cons
- Pros: Encourages strong monitoring and resilience planning.
- Cons: Requires investment in detection and response capabilities.
