# Defense in Depth
## Gambaran Umum

Defense in Depth melapiskan beberapa kontrol keamanan (network, host, aplikasi, data) sehingga kegagalan pada satu kontrol dapat diminimalkan oleh kontrol lain. Strategi ini memberikan perlindungan komprehensif terhadap berbagai vektor serangan.

## Kapan digunakan
Diterapkan di seluruh sistem untuk meningkatkan ketahanan terhadap berbagai ancaman.

## Contoh
Segmentasi jaringan, firewall, kontrol perimeter, pengecekan di tingkat aplikasi, dan enkripsi saat istirahat dan transit.

## Kelebihan / Kekurangan
- Kelebihan: Mengurangi ketergantungan pada satu kontrol; meningkatkan postur keamanan.
- Kekurangan: Kompleksitas dan biaya operasional meningkat.

## Referensi
- Praktik terbaik arsitektur keamanan.
