# Defense in Depth
## Overview

Defense in Depth layers multiple security controls (network, host, application, data) so that a failure in one control is mitigated by others. This strategy provides comprehensive protection against various attack vectors.

## When to use
Adopt across systems to increase resilience against a range of threats.

## Example
Network segmentation, firewalls, perimeter controls, application-level checks, and encryption at rest and in transit.

## Pros / Cons
- Pros: Reduces reliance on a single control; improves overall security posture.
- Cons: Increased complexity and operational cost.
