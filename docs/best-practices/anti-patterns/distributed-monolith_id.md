# Distributed Monolith
## Gambaran Umum

Distributed Monolith adalah anti-pattern di mana sistem bergaya microservices memiliki keterkaitan ketat sehingga tidak bisa dideploy atau di-scale secara independen. Ini kehilangan banyak manfaat microservices sambil menambah kompleksitas distribusi, membuat deployment berisiko dan lambat. Untuk mitigasi, tentukan bounded contexts yang jelas, tingkatkan otonomi layanan, dan refactor untuk memisahkan deployment dan kepemilikan data.

## Mengapa bermasalah
Kehilangan banyak manfaat microservices sambil menambah kompleksitas distribusi, membuat deployment berisiko dan lambat.

## Mitigasi
Tentukan bounded contexts yang jelas, tingkatkan otonomi layanan, dan refactor untuk memisahkan deployment dan kepemilikan data.

## Referensi
- Panduan anti-pattern microservices.
