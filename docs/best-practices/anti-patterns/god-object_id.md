# God Object
## Gambaran Umum

God Object adalah anti-pattern di mana satu kelas atau modul mengumpulkan terlalu banyak tanggung jawab sehingga menjadi hambatan pemeliharaan dan evolusi. Ini meningkatkan coupling, mengurangi modularitas, dan membuat kode sulit diuji dan diubah. Untuk mitigasi, refactor dengan memecah tanggung jawab menjadi modul yang lebih kecil, terapkan prinsip single responsibility, dan tambahkan pengujian.

## Mengapa bermasalah
Meningkatkan coupling, mengurangi modularitas, dan membuat kode sulit diuji dan diubah.

## Mitigasi
Refactor dengan memecah tanggung jawab menjadi modul yang lebih kecil, terapkan prinsip single responsibility, dan tambahkan pengujian.
