# Spaghetti Code
## Gambaran Umum

Spaghetti Code adalah anti-pattern yang ditandai dengan kode kusut dan tidak terstruktur dengan pemisahan tanggung jawab buruk, biasanya akibat shortcut dan kurang desain. Ini membuat sulit dipahami, dikembangkan, dan diuji, sehingga menaikkan biaya perubahan. Untuk mitigasi, perkenalkan abstraksi yang jelas, refactor menjadi modul/fungsi, dan tingkatkan cakupan pengujian.

## Mengapa bermasalah
Sulit dipahami, dikembangkan, dan diuji, sehingga menaikkan biaya perubahan.

## Mitigasi
Perkenalkan abstraksi yang jelas, refactor menjadi modul/fungsi, dan tingkatkan cakupan pengujian.

## Referensi
- Sumber clean code dan refactoring.
