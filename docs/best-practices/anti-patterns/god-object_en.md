# God Object
## Overview

God Object is an anti-pattern where a single class or module accumulates too many responsibilities, becoming a maintenance and evolution bottleneck. This increases coupling, reduces modularity, and makes the codebase hard to test and change. To mitigate, refactor by splitting responsibilities into smaller cohesive modules, apply single responsibility principle, and write tests.

## Why it's a problem
