# Spaghetti Code
## Overview

Spaghetti Code is an anti-pattern characterized by tangled, unstructured code with poor separation of concerns, typically resulting from shortcuts and lack of design. This makes it hard to understand, extend, and test, increasing the cost of changes. To mitigate, introduce clear abstractions, refactor into modules/functions, and improve test coverage.

## Why it's a problem
It is hard to understand, extend, and test, increasing the cost of changes.

## Mitigation
Introduce clear abstractions, refactor into modules/functions, and improve test coverage.
